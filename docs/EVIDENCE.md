# 原始文件核验 v1

`verify SNAPSHOT.json BUNDLE.json` 核对文件字节与快照摘要。退出码：内容匹配为 0，摘要或清单不匹配为 1，读取、结构或路径错误为 2。

清单示例见 `examples/evidence/bundle.json`。`schema_version` 必须为 1；每个测试指定 `id`、`input`、`answer`，每个解法指定 `id` 和非空 `files` 列表。路径相对于清单目录，实际目标须位于该目录内。解法路径采用规范 `/` 分隔形式且不能重复。

摘要协议以原始字节为准，不转换换行符。SHA-256 输入为：

1. UTF-8 编码的域名称，加一个 NUL 字节。
2. 对每个字段依次添加 8 字节无符号大端长度，然后添加字段原始字节。

测试域为 `moonverdict-test-v1`，字段依次为输入字节、答案字节。解法域为 `moonverdict-solution-v1`，按路径排序，逐个添加路径 UTF-8 字节及对应文件字节。首版建议使用 ASCII 相对路径。

快照和观测清单必须具有相同 ID 集合；缺项、多项、摘要不同均报告，重复观测 ID 拒绝。文件及 SHA-256 由 Node 内置接口提供，结构校验和比较由 MoonBit 核心实现。

样例预期摘要通过 Python hashlib 独立计算，命令行验证将 Node 实际计算值与之比较。样例解法仅作为文件内容参与核验，没有执行。字节匹配不能证明这些文件曾参与指定的运行，因此该命令始终输出 `run_binding_verified: false`。常规判定报告不因单独运行本命令而自动升级证据等级。
